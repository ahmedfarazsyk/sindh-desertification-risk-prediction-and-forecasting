# Desertification Dashboard (Frontend)

This is the Next.js frontend for the Desertification Dashboard project.

## Setup Instructions

### 1. Requirements
- Node.js 18+
- npm (or yarn/pnpm)

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Variables
Copy the `.env.example` file to `.env.local`:
```bash
cp .env.example .env.local
```
Update any required environment variables in `.env.local` (e.g., setting `NEXT_PUBLIC_API_URL` to point to the backend).

### 4. Start the Development Server
```bash
npm run dev
```
The dashboard will be available at `http://localhost:3000`.
